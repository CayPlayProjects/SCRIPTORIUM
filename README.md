### 🏛 О проекте

**SCRIPTORIUM** создан для разработчиков и авторов, которым нужна легкая, быстрая и эстетичная среда для набросков кода, ведения логов разработки и написания `README.md` файлов без тяжелых облачных редакторов.

- 📖 **Встроенная шпаргалка:** при первом запуске открывается подробное руководство по синтаксису.
- ☑️ **Интерактивные задачи:** кликайте по чекбоксам в правой панели предпросмотра — текст заметки обновится автоматически.
- 🎨 **6 палитр:** `Scriptorium`, `Emerald`, `Obsidian`, `Amber`, `Nord` и `Light`.
- 💾 **Экспорт:** мгновенная выгрузка любой записи в файл `.md`.
